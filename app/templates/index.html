About The System

Explainable Brain Tumor Classification

This academic project uses an EfficientNetB0 deep learning model to classify brain MRI images into four categories. Grad-CAM is used to provide a visual explanation of the model prediction.

🎯

4-Class Classification

Glioma, Meningioma, Pituitary Tumor, and No Tumor.

🤖

Deep Learning

EfficientNetB0 transfer learning is used for MRI image classification.

🔎

Explainable AI

Grad-CAM highlights image regions that influence the model prediction.

A deep learning based academic project for multi-class classification of brain MRI images.

Project Overview

BrainTumor AI is an academic research prototype designed to classify brain MRI images into four categories using deep learning.

The system uses transfer learning with an EfficientNetB0 model and provides an explainability feature using Grad-CAM.

Explainable AI

The application uses Grad-CAM (Gradient-weighted Class Activation Mapping) to provide a visual explanation of the model's prediction.

The generated heatmap highlights image regions that contributed to the model's prediction, helping users understand which areas influenced the classification.
